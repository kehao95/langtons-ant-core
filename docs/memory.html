02 · A fixed seed size, a growing delay

Twenty black cells. Thirty-one intervening events. No uniform age limit.

For every even \(n\ge20\), an explicit complete twenty-cell input writes cell \((0,2)\) at update 60. That cell survives until update \(624n-1516\). Exactly 31 \(S_{128}\) events occur strictly between these two updates.

The small inputs above are replayed literally. This calculator evaluates the proven affine formulas using exact integers for any entered even n; it does not simulate the enormous examples.
