coverage arguments. Exact computational sources and frozen reports are in:

The entrypoint validates the source manifest, uses disposable working copies,
and compares rebuilt reports to their frozen values. Program agreement is a
control on implementation; universal claims use the written inductive, algebraic
or geometric arguments in the article. These components are not Lean formalizations.
