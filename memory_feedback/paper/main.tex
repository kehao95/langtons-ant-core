\begin{abstract}
We study the failure of finite-recency prediction in the classical
Langton ant. For each memory length \(D\), the next old-black read is
decidable on every finite input, with polynomial bit complexity for
fixed \(D\). Finite arithmetic segments retain the complete black field
as an XOR expression across long predicted flights, making the event
interface exactly iterable. We prove quadratic finite-event time budgets
and an endpoint-tube theorem. These imply decidability of spatially
filtered events and force every non-eventually-translating orbit to
consume newly created, arbitrarily old black memory outside every fixed
finite region. A birth-filtered total query returns the first such lifetime
created since its source checkpoint, together with exact birth, consumption
and complete endpoint. Uniform deadlines yield
\(\Omega(\sqrt H/\log H)\) late-born lifetimes at simultaneously growing
radius and age on every non-eventually-translating orbit.
An explicit twenty-black family has unbounded feedback
lifetime with exactly 31 intervening \(S_{128}\) events, showing why
spatial scale cannot be removed from a uniform lifetime bound.
\end{abstract}

\section{Introduction}\label{introduction}

A Langton ant can read a cell long after it last wrote there. Predicting
the next turn from a finite suffix therefore raises two questions: when
can an old black cell first invalidate the prediction, and what complete
state remains after the resulting long excursion? We answer both
questions by combining a finite suffix predictor with exact arithmetic
on periodic rays and finite XOR expressions for the entire black field.

The resulting event interface also exposes the geometry of memory
feedback. Every interval ending in a prediction failure lies near the
segment joining its endpoints. A fixed finite region can consequently
host only a bounded consecutive run of failures. Spatially filtered
event queries are decidable, and every non-eventually-translating orbit
must repeatedly consume long-lived black memory outside every fixed
region. Tracking last writers strengthens this to an exact first-lifetime query:
initial inventory can be distinguished from newly generated memory even
when the same coordinate is reused. Uniform event budgets then provide a
simultaneous growing-scale lower bound. A twenty-black construction shows why a spatial parameter is
essential even when initial mass and the number of intervening events
are fixed.

Gajardo's symbolic treatment already relates long return paths to infinite
memory effects {[}1{]}. Our starting point is the specific old-black-read
predicate, whose next occurrence can be computed from each complete finite
input. This is a different target from arbitrary-cell visitation, which
Gajardo, Moreira and Goles prove P-hard using finite circuit configurations
{[}6{]}. Their infinite computation construction uses an infinite background.
The event algorithms here apply to finite support and are polynomial in
sparse input bit length for fixed memory length and fixed spatial filter.

The periodic read test uses full-drift chronology {[}3{]}, and the finite-region
argument uses the square escape theorem {[}4{]}. Highway multiplicity for
generalized rules is studied in {[}2{]}; the dynamics here use the classical
two-colour rule. The contributions are the quantitative event interface,
exact continuation with full history, geometric event budgets, exact birth-filtered
feedback and its growing-scale consequence, and the
construction separating those budgets from bounds based only on mass and
event count.

\section{Model and results}\label{model-and-results}

A complete state \(X=(B,p,h)\) has finite \(B\subset\mathbb Z^2\). White
turns right, black turns left; flip then move. Let \(F\) be the
invertible update. For \(D\ge1\), write \(Q=2^D\) and define the
intrinsic event \[S_D(X)\iff p\in B\quad\text{and}\quad
\operatorname{pos}(F^{-j}X)\ne p\quad(1\le j\le D).\] Its
inverse-history definition applies at the input time as well as later.
It records an old black read. The factor-language event \(J_{10}\) and
the physical gate segmentation are different predicates; none is
substituted for \(S_D\) in the following bounds.

\textbf{Prediction and continuation.} The next \(S_D\), if present,
occurs before \(Q(R+2Q+10)\), where \(R\) is the initial head-relative
radius. Existence is decidable in polynomial bit time for fixed \(D\) on
sparse explicit input. Finite XOR segments allow the exact full endpoint
to be returned without expanding every skipped write. The first \(n\)
events and their full encoded endpoint are computable in
\(f(D)\operatorname{poly}(m+n+b)\), where \(m\) is the initial mass,
\(b\) the coordinate bit length, and \(n\) is measured numerically.

\textbf{Geometry.} With \(W=\operatorname{diam}_\infty(B\cup\{p\})\),
the time just after event \(n\), whenever it exists, is at most
\[T_D(n,W)=Qn(W+2Q+10)+5Q^2n(n-1).\] Between a starting head \(p\) and
its next event cell \(e\), the entire finite trajectory stays within
\(3Q+1\) of \([p,e]\). After joining successive event locations the
corresponding tube radius is \(3Q+2\).

\textbf{Remote feedback.} For every fixed finite region \(K\), existence
of an \(S_D\) outside \(K\) is decidable. If a trajectory is not
eventually a nonzero translator, then for every \(D,K,T\) there are
infinitely many black lifetimes born after \(T\), lasting more than
\(D\), and consumed outside \(K\). The properties hold simultaneously
for the same lifetimes.

\textbf{Newly generated feedback.} The first exterior old lifetime born
since the input checkpoint is totally computable, including its exact birth,
consumption and complete post-state. On a non-eventually-translating orbit,
Section~\ref{sec:birth-feedback} gives
\(\Omega(\sqrt H/\log H)\) lifetimes with birth after \(H^{1/4}\) up to
integer rounding, radius of order \(\log H\), and age of order
\(\log\log H\).

\textbf{Spatial-scale obstruction.} For every even \(n\ge20\), a
complete 20-black initial state writes a cell at time 60 and next reads
it at \(624n-1516\), with exactly 31 intervening \(S_{128}\) events. Its
first permanent P104 time is \(624n-742\). Thus no lifetime bound
depending only on \(D\), intervening event count and initial mass can
hold uniformly.

\section{Predicting the next old-black
read}\label{predicting-the-next-old-black-read}

\subsection{Definitions and an intrinsic finite-local
target}\label{sm-1}

Write X=(B,p,h), headings N,E,S,W. Let F be the literal update. Define

\begin{verbatim}
R(X)=max({||q-p||_infinity:q in B} union {0}).
\end{verbatim}

For integer D\textgreater=1, define the stale-black predicate

\begin{verbatim}
S_D(X) iff p in B and position(F^(-k) X) != p for every 1<=k<=D.       (SM1)
\end{verbatim}

The inverse is literal and unique: q=p-dir(h), flip q, and undo a right
turn when q is black in the supplied post-state, otherwise undo a left
turn. Only cells at distance at most D from p are read during D inverse
steps. Consequently (SM1) is a translation-invariant FINITE LOCAL
PREDICATE on the present colouring and heading. It does not use an
infinite historical oracle.

Using the intrinsic backward orbit makes (SM1) defined even at input
time zero. At forward times t\textgreater=D, it says exactly: the
current read is black and the same cell has not been read in the
previous D updates. A very old WHITE reread is not an S\_D event. A
never-yet-read initial black cell can be an S\_D event too. This
convention is distinguished from an age defined only after time zero.

Let tau\_D(X)=min\{t\textgreater=0:S\_D(F\^{}t X)\}, when it exists.
This target comprises infinitely many full states; the result below is
not just specified-full-state reachability.

\subsection{Prediction identity: no event means one unique next
turn}\label{sm-2}

For a D-letter R/L word w, execute its geometric turns from a fixed
pose. Compare the final position to the preceding D pre-update
positions. If the last matching position has index j, set
f\_D(w)=opposite(w\_j); if there is no match, set f\_D(w)=R. This
depends only on w: translation and quarter turns preserve position
equality.

Recover the actual previous D turns of X using F\^{}(-1), and call them
w(X). The following equality is exact for EVERY finite state:

\begin{verbatim}
actual_turn(X) != f_D(w(X))  iff  S_D(X).                           (SM2)
\end{verbatim}

Moreover the only possible mismatch is predicted R versus actual L.

Proof: a recent previous read fixes the current colour to its flipped
value. With no recent previous read, f\_D predicts R. This is wrong
precisely when the current cell is black. Old white cells and virgin
white cells both give R. The backward suffix is part of the actual
orbit, so inconsistent fake histories cannot enter this argument.

While S\_D is absent, suffixes evolve autonomously as

\begin{verbatim}
w -> suffix_(D-1)(w) f_D(w).
\end{verbatim}

This is a deterministic map on Q=2\^{}D states. Its generated infinite
turn word has a transient shorter than Q and period at most Q. This
alone does NOT prove that the physical ant follows the word forever:
distant black cells may cause a first mismatch. The next section bounds
WHEN any such mismatch can occur.

\subsection{First mismatch against an ultimately periodic motion
plan}\label{sm-3}

Consider a complete finite state Y of radius r and a proposed periodic
turn word u of length P, with matching start/end heading and
displacement d!=0. Let q\_i, 0\textless=i\textless P, be its relative
pre-update positions, q\_0=0. Its proposed future reads are

\begin{verbatim}
q_i + k*d,  k>=0.
\end{verbatim}

Earlier periodic reads of the same cell correspond exactly to

\begin{verbatim}
q_j-q_i = l*d, l>=0, and (l>0 or j<i), with k>=l.                     (SM3)
\end{verbatim}

Each such l is at most P: the finite footprint's pairwise
infinity-distance is at most P, and
\textbar\textbar d\textbar\textbar\_infinity\textgreater=1. Earlier-read
parity can change only at these finitely many thresholds l.

The initial colour contribution is 1{[}q\_i+k*d in B\_Y{]}. If this is
nonzero then

\begin{verbatim}
k*||d||_infinity <= r+||q_i||_infinity <= r+P,
\end{verbatim}

so k\textless=r+P. It is a one-epoch contribution, turning on at k and
off at k+1. Thus the colour required by literal dynamics at each phase i
is

\begin{verbatim}
1[q_i+k*d in B_Y] XOR parity(number of eligible pairs in (SM3)).       (SM4)
\end{verbatim}

All changes occur by epoch r+P+1. Testing every breakpoint, including
the last infinite constant interval, is necessary and sufficient for
infinite execution. If there is a mismatch, its FIRST time is strictly
below

\begin{verbatim}
P*(r+P+2).                                                         (SM5)
\end{verbatim}

This statement concerns the first mismatch, not a hypothetical
trajectory after an earlier mismatch. Induction in time ensures that the
proposed path agrees with the real path up to that first point.

If u does not restore heading, repeat it two or four times to restore
heading. The resulting displacement is zero, since the quarter-rotated
displacement vectors sum to zero. If heading is restored but d=0
already, use u itself. In either case let v be the closed-pose block, of
length at most 4P. If two consecutive copies of v were both physically
valid, all flips would occur twice and the complete state would recur.
Such an orbit would remain in finitely many cells forever, impossible
for the classical ant. Hence a first mismatch occurs before
2\textbar v\textbar\textless=8P updates.

For clarity, the elementary no-bounded-orbit argument used here is as
follows. If the set I of infinitely read cells were nonempty and finite,
choose a cell maximizing x+y. After the north and east neighbours have
ceased being read, the checkerboard/heading-axis invariant fixes the
only possible entering and leaving directions at that cell. This
requires the same read colour on every sufficiently late visit,
contradicting colour alternation. No periodicity, finite-support HC or
new computational evidence is assumed in this argument.

\subsection{Uniform waiting theorem}\label{sm-4}

\textbf{Theorem 1.} For every finite state X and D\textgreater=1, with
Q=2\^{}D, put

\begin{verbatim}
H_D(X)=Q*(R(X)+2Q+10).                                             (SM6)
\end{verbatim}

Exactly one of the following occurs:

\begin{itemize}
\tightlist
\item
  tau\_D(X) exists and 0\textless=tau\_D(X)\textless H\_D(X);
\item
  S\_D never occurs at any nonnegative time; the ant has a nonzero
  translating periodic trace with period \textless=Q, beginning at a
  time \textless=Q.
\end{itemize}

Thus observing no S\_D event at times 0,\ldots,H\_D(X)-1 proves that
none ever occurs.

Proof: construct the autonomous suffix trajectory. If a physical
mismatch occurs before the first repeated suffix, (SM2) gives the event
within Q updates. Otherwise at a repetition time j\textless=Q, the
physical trajectory has followed the plan and a periodic suffix cycle of
length P\textless=Q begins from its current phase. The current complete
radius is at most R(X)+j: initial black cells move relative to the ant
by at most j; any newly black cell is also within j steps of it.

For nonzero translational drift, (SM5) bounds a first future mismatch by

\begin{verbatim}
j+P*(R(X)+j+P+2) <= Q*(R(X)+2Q+3).
\end{verbatim}

For a closed geometric plan, the other bound is j+8P\textless=9Q. Both
are strictly covered by (SM6). If no mismatch exists, the planned
periodic trace is the exact infinite future. A closed or rotating
periodic plan was excluded above, so its drift is nonzero. By (SM2), no
mismatch also means no S\_D event. This proves both the waiting bound
and the dichotomy.

No width, cone, retreat, mass, visit-count, future-active set, or
hypothesized computation-time bound is supplied as an extra premise. The
ONLY spatial size in (SM6) is the computable radius of the actual finite
input.

\subsubsection{What is the corresponding decision
problem?}\label{what-is-the-corresponding-decision-problem}

The family

\begin{verbatim}
L_D={X:there exists t>=0 with S_D(F^t X)}                            (SM7)
\end{verbatim}

is recursive, uniformly in D. This is a genuine all-input decision
theorem for a family of local predicates, not a HIGHWAY algorithm. Even
an input-dependent computable D(x) cannot make a reduction of an
undecidable source language to (SM7). An arbitrary HALT pattern is NOT
automatically of this form.

A simple decision algorithm simulates the explicit finite bound (SM6).
The implementation uses the stronger symbolic version: only the first
suffix cycle is produced, then all-future ray/flip arithmetic finds the
first event, or verifies a permanent event-free trace. No simulation to
a late arithmetic collision is necessary.

\subsubsection{Bit complexity of the implemented first-event
decision}\label{bit-complexity-of-the-implemented-first-event-decision}

With an explicit sparse list of m black coordinates of bit length at
most b, the symbolic first-event algorithm uses time 2\^{}\{O(D)\} times
a polynomial in the input length. In particular, for every fixed D,
language (SM7) is decidable in polynomial time in the sparse
BINARY-coordinate input size.

Indeed inverse-history recovery uses D steps; the suffix search uses at
most Q=2\^{}D states; its explicit black field has at most m+Q+D cells.
The candidate word has length at most Q, and the ray verifier checks
O(Q*m+Q\^{}2) phase/cell and phase/phase relations. All coordinate,
epoch and offset arithmetic has bit length polynomial in b+D.
Closed-pose control replay costs at most 8Q updates. Ordinary
polynomial-time set/dictionary implementations suffice. The parameter
factor grows exponentially in D.

For fixed D the upper bound is linear in R. This order cannot in general
be replaced by a radius-independent constant: take a certified
event-free P104 state with D=128 and insert one remote black cell at a
virgin frontier site k highway periods ahead. Until its first read the
original periodic trajectory is unchanged. The first event is at
104k+O(1), while R=2k+O(1). The phase-ray calculation gives the
constants exactly. The full input coordinates supply the growing scale.

\section{Exact continuation with complete
history}\label{exact-continuation-with-complete-history}

\subsection{Finite XOR segments, not infinite periodic
background}\label{xor-2}

For integer a,v and n\textgreater=1 put

\begin{verbatim}
Seg(a,v,n) = {a+j*v:0<=j<n}.
\end{verbatim}

If n\textgreater1 require v!=0. An encoded colouring consists of a
finite list of segments and means their SYMMETRIC DIFFERENCE. A
singleton is a segment of length one. Thus an explicit finite black set
embeds exactly as singleton terms. Every encoded state still has finite
support, including after a huge skipped prefix. Overlaps cancel modulo
two; they are never silently interpreted as union.

Membership of a point is the parity of the segments containing it. For a
nontrivial segment, containment is one integer-collinearity test
followed by a finite-index interval test. A literal update and its
inverse therefore remain exactly computable without expanding any
segment. Identical singleton terms may be cancelled syntactically; no
cell is removed because it is presumed irrelevant. The list is not
canonical: distinct expressions may encode the same finite set.

\subsection{Exact first mismatch against a periodic motion
plan}\label{xor-3}

Let a supplied word u have length P, restore heading, and have nonzero
drift d. Its pre-update phase positions are q\_i. The proposed future
reads are

\begin{verbatim}
q_i+k*d, 0<=i<P, k>=0.
\end{verbatim}

As in the earlier finite-field verifier, an earlier periodic read at
this same position exists for each pair (j,r) satisfying

\begin{verbatim}
q_j-q_i=r*d, r>=0, and (r>0 or j<i), with k>=r.
\end{verbatim}

Each pair toggles read parity at the one threshold r. These are finite
in number.

Now intersect a phase ray with ONE old finite segment:

\begin{verbatim}
q_i+k*d=a+j*v, k>=0, 0<=j<n.                       (XOR1)
\end{verbatim}

If d and v are not parallel, determinants give at most one integer pair
(k,j), which is tested against the bounds. If they are parallel but
a-q\_i is not, there is no intersection. Otherwise reduce a nonzero
coordinate of d to

\begin{verbatim}
A*k-B*j=C, A>0.
\end{verbatim}

Writing g=gcd(A,\textbar B\textbar), there is no solution unless g
divides C. When it does, solutions for k form one residue class modulo
\textbar B\textbar/g. The finite bounds on j supply an interval
{[}lo,hi{]}, intersected with k\textgreater=0. Thus (XOR1) is either
empty, a singleton, or a finite arithmetic progression of epochs. The
singleton case also handles length-one terms independently of the unused
stride.

For a phase i, its initial-black contribution is the XOR of membership
in these finitely many epoch progressions. Partition k\textgreater=0 at
all progression starts, ends+1, and earlier-read thresholds. Within each
partition interval, the active progressions are fixed; their combined
parity is periodic in k, with period dividing the least common multiple
of their moduli. The earlier- read parity is constant on that interval.
Test a whole residue period, or the shorter finite interval. The final
unbounded interval has no active finite segment and needs one parity
test.

This is an exhaustive finite algorithm, not sampling a few epochs. It
decides whether u\^{}omega is the exact future; otherwise it finds the
first mismatch. Until the first mismatch the proposed and literal paths
agree by induction, so its position and time are real. The running time
can depend on a large lcm. No polynomial-time claim is made for
arbitrary segment-encoded input strides.

\subsection{Exact algebra of the skipped writes}\label{xor-4}

Suppose the first n proposed updates have been verified (including n=0).
For each phase i put

\begin{verbatim}
n_i=max(0, floor((n-1-i)/P)+1).
\end{verbatim}

Its updated cells are exactly Seg(q\_i,d,n\_i), omitting phases with
n\_i=0. Therefore the complete endpoint is

\begin{verbatim}
B_n = B_0 XOR XOR_(0<=i<P,n_i>0) Seg(q_i,d,n_i).      (XOR2)
\end{verbatim}

If n=kP+i, the endpoint position is q\_i+k*d and its heading is the
recorded heading before phase i. Equation (XOR2) accounts for every
flip, including self-overlap, overlap between phases, and overlap with
every old segment. It adds at most P terms regardless of n.~The helper
applying (XOR2) does NOT assert that an arbitrary geometric word is
physically executable; its caller must first establish validity through
the chosen prefix.

At the first mismatch of the recency-D predictor, the planned turn is R
and the actual turn is L. Toggle that point in (XOR2), turn left and
move once. This is the exact full input for the next macro, with no
separate history oracle: the needed preceding D positions are recovered
by the literal inverse.

\subsection{Total single-event macro and finite iteration}\label{xor-5}

For D\textgreater=1 put Q=2\^{}D. The previous suffix identity says that
no S\_D event means one deterministic next turn from the latest D-turn
word. There are Q words. Execute at most Q matching turns until an event
or a repeated suffix occurs. In the latter case the prediction has a
period P\textless=Q.

If its geometric period is nontranslating or rotates the heading, two
copies of a closed-pose block of length at most 4P expose a mismatch:
otherwise the complete state would recur and the ant would be
permanently confined. Literal no-bounded-orbit excludes that. Replaying
at most 8P steps handles this case.

For nonzero translation apply Subsection \ref{xor-3}. A valid infinite
word gives a certified permanent event-free tail. Otherwise (XOR2) and
one real black update give the next full post-event state. Every input
is finite and every arithmetic search here is finite, so this single
macro is total without caller resource caps.

If the input expression has M terms, an event output has at most

\begin{verbatim}
M+9Q+1 terms.                                         (XOR3)
\end{verbatim}

The loose uniform value covers Q preliminary writes, at most 8Q
closed-plan writes, or at most Q new periodic segment terms, and the
final event. Inverse history recovery is temporary and does not alter
the returned physical field. Nontrivial new segment strides are period
drifts; both coordinate magnitudes are at most Q. The same statement
applies to a terminating tail's entry state.

After n successive event outputs from an explicit m-black input, the
expression has at most m+n(9Q+1) terms. Every individual call
terminates; the iteration over ALL events is not asserted to terminate.
\texttt{event\_prefix} computes the first n events, or stops earlier on
a certified event-free tail. Reaching its finite requested event budget
is neither HALT nor NO-HIGHWAY. Optional resource caps return
INCONCLUSIVE and do not change the mathematical total algorithm.

\subsection{Parameterized complexity of a FINITE event
prefix}\label{xor-6}

For an explicit sparse input with m black cells, coordinate bit length
b, fixed D, and an event count n measured numerically (or in unary), the
first n events and their complete compressed endpoint are computable in

\begin{verbatim}
f(D) * poly(m+n+b).                                   (XOR4)
\end{verbatim}

This is not a polynomial bound in log(n), an ordinary-step cutoff, or a
claim that large D is practical. f may be doubly exponential in D.

Here is the bound rather than an assumption of compactness. All initial
terms are singletons, and every nontrivial generated stride has
components of magnitude at most Q by (XOR3). A parallel intersection
modulus is \textbar B\textbar/g\textless=Q. Hence all residue periods
divide Lambda\_Q=lcm(1,\ldots,Q), a function only of D. The numbers of
old terms, phase pairs and interval endpoints are polynomial in m+n for
fixed Q. One whole residue enumeration therefore costs a factor at most
Lambda\_Q, not a factor equal to the huge skipped physical time.

For bit lengths use the already proved event deadline, or rederive it by
R(F\^{}t X)\textless=R(X)+t. For this bit-length argument the elementary
preliminary bound suffices. With C=R(X)+2Q+10, the nth event, if
present, occurs before

\begin{verbatim}
C*((Q+1)^n-1).
\end{verbatim}

All segment endpoints come from the initial support or actual reads
before this time. Their binary coordinate and length encodings thus use
O(b+n(D+1)) bits. No cancellation-dependent radius computation or
hypothesized mass bound is required. Membership, determinants, gcd and
residue arithmetic consequently have polynomial bit cost; combining
these bounds proves (XOR4).

General arbitrary-stride symbolic inputs retain totality but are outside
(XOR4)'s explicit-input/generated-stride premise. The lcm cost must not
be hidden.

\section{Quadratic event budgets}\label{quadratic-event-budgets}

Put \(C(X)=\operatorname{conv}(B\cup\{p\})\). A finite macro ends just
after its first \(S_D\) update. We prove the convex-halo enclosure
\[C(X_{\rm next})\subset C(X)+[-5Q,5Q]^2,\] including every intermediate
head position. Iterating gives \(C(X_n)\subset C(X_0)+[-5Qn,5Qn]^2\) and
the stated \(T_D(n,W)\). In the proof below, (A) denotes this one-macro
enclosure, and (B1)--(B3) denote the iterated enclosure,
\(R(X_n)\le W+10Qn\), and the quadratic time bound, respectively. The
first-event waiting estimate is the predictor bound proved above,
denoted (GEO1) in this section.

\subsection{A geometric lemma for ANY translating periodic motion
plan}\label{geo-3}

Start at Y=(B,p,h). Let a nonempty word u of length P restore heading
and have nonzero drift d.~Write its pre-update phase positions as
q\_0,\ldots,q\_(P-1), q\_0=p. The prescribed infinite positions are
q\_i+k*d for k\textgreater=0. These are at first just a MOTION PLAN:
executability is not assumed.

Until its first read mismatch with literal LR dynamics, the plan is the
actual orbit, by induction on updates. All earlier plan writes then
legitimately contribute to its current read colour.

\subsubsection{3.1 Only finitely many old-field and self-read changes
matter}\label{only-finitely-many-old-field-and-self-read-changes-matter}

A previous phase j visits the position q\_i+k*d precisely when

\begin{verbatim}
q_j-q_i=s*d,  s>=0, and (s>0 or j<i),  k>=s.
\end{verbatim}

For each phase pair this toggles parity at one threshold s. Let K\_self
be the maximum of all these s and zero. Since the two phase points are
connected by at most P unit moves within the block,

\begin{verbatim}
K_self*||d||_infinity <= P.                              (GEO3)
\end{verbatim}

Let K\_B be the greatest epoch k\textgreater=0 for which some q\_i+k*d
is in the ACTUAL finite set B. If there is no such pair, put K\_B=-1.
This maximum is finite. If K\_B\textgreater=0, retain one corresponding
black point

\begin{verbatim}
z=q_j+K_B*d in B.                                       (GEO4)
\end{verbatim}

Put

\begin{verbatim}
K=max(0,K_self,K_B+1).                                  (GEO5)
\end{verbatim}

At every epoch k\textgreater=K the old field contributes zero at every
phase and every self-read threshold has stabilized. The prescribed
read-colour vector is thus constant in k there. If a mismatch exists at
all, a FIRST mismatch must occur within epochs 0,\ldots,K, hence at an
offset strictly below (K+1)*P.

This remains true if early old-black cells temporarily mask a
self-inconsistent motion plan. Such masking ends by K\_B+1 and has not
been silently discarded. The argument works for either direction of
colour mismatch; its later suffix instantiation has the special R-to-L
mismatch property.

\subsubsection{3.2 The same cutoff bounds SPACE by a constant halo, not
by travel
time}\label{the-same-cutoff-bounds-space-by-a-constant-halo-not-by-travel-time}

We prove that every prescribed read in epochs 0,\ldots,K is in

\begin{verbatim}
conv(B union {p}) + [-3P,3P]^2.                          (GEO6)
\end{verbatim}

If K=K\_self, (GEO3) gives
\textbar\textbar k*d\textbar\textbar\textless=P for all k\textless=K,
while \textbar\textbar q\_i-p\textbar\textbar\textless=P. These points
are within 2P of p, already sufficient for (GEO6). If K=0 the statement
is immediate.

Otherwise take K=K\_B+1 and the old black point z from (GEO4). For
0\textless=k\textless=K\_B and K\_B\textgreater0, put lambda=k/K\_B.
Then

\begin{verbatim}
q_i+k*d = (1-lambda)*p+lambda*z
          +(q_i-p)-lambda*(q_j-p).
\end{verbatim}

The first two terms lie on the segment {[}p,z{]}; the remainder has
l\_infinity norm at most 2P. For k=K\_B+1, add d to the k=K\_B
expression; \textbar\textbar d\textbar\textbar\textless=P, giving 3P.
When K\_B=0, the two epochs k=0,1 are within 2P of p directly. Thus
(GEO6) holds in every case, including ties between maxima in (GEO5).

In particular, if the plan has a first physical mismatch, ALL positions
before and AT that read satisfy (GEO6). Executing the actual mismatched
move instead of the planned one adds at most one unit of halo. The old
field and every new black cell at the resulting complete endpoint also
lie inside (GEO6) enlarged by one, since each new black cell is a
previously updated location.

There is no claim that an arbitrarily long VALID event-free translating
tail stays in (GEO6). The finite mismatch is an essential hypothesis.

\subsection{Proof of Theorem A, including rotating/closed
plans}\label{geo-4}

Run the order-D predictor from X until an immediate S\_D event or a
repeated suffix. Before the repetition j\textless=Q, all written cells
and the head are within Q of the original head, so

\begin{verbatim}
C(X_j) subset C(X)+[-Q,Q]^2.                             (GEO7)
\end{verbatim}

An immediate event and its outgoing move have the claimed bound
trivially. At a repeated suffix the plan cycle has length P\textless=Q.

If the heading is restored and drift is nonzero, apply Subsection
\ref{geo-3} from the full state X\_j. A finite next event is exactly its
first mismatch. By (GEO6),(GEO7) and the real final update, the entire
macro stays within halo

\begin{verbatim}
Q+3P+1 <= 4Q+1 <= 5Q.                                  (GEO8)
\end{verbatim}

If the cycle rotates heading, repeat it at most four times to get a
closed-pose plan; if its displacement is already zero use one copy. This
closed plan has length L\textless=4P. Each point of a closed unit-step
walk is reachable from its origin in either time direction, so its
distance from the origin is at most L/2\textless=2P. If TWO copies of
that plan were fully executable, they would flip each cell an even total
number of times and restore the pose, repeating the complete state.
Consequently a mismatch occurs before 2L\textless=8P. All positions up
to its read are in the same closed footprint, and the true mismatched
move adds one unit. The resulting source-relative halo is at most
Q+2P+1\textless=5Q.

Every unchanged black cell was already in C(X), and every newly black
cell was on the bounded read footprint. This proves both the path and
complete-support parts of (A). Neither the geometric convex-envelope
theorem nor deleting any archive is needed for this new bound.

\subsection{Proof of Theorem B and the improved coordinate bit
bound}\label{geo-5}

Minkowski sums of l\_infinity balls add their radii. Applying (A)
successively proves (B1), and also covers the complete trajectory
between checkpoints. The l\_infinity diameter of
C(X\_0)+{[}-5Qn,5Qn{]}\^{}2 is W+10Qn. Both the current head and each
current black cell lie in that set, proving (B2).

The nth macro starts after n-1 events. Because event offset \textless{}
(GEO1), and the post-event duration is offset+1, its duration is at most

\begin{verbatim}
Q*(W+10Q*(n-1)+2Q+10).
\end{verbatim}

Summing from 1 through n proves (B3). These are integer non-strict
bounds for post-event time; the event itself occurred one update
earlier.

The old exponential event deadline remains sound; this is a stronger
conversion, not a retraction of its proof. No claim of a best constant
or sharp lower bound is made. Smaller D can produce more events, and the
constants are exponential in D; the comparison is for each FIXED D as n
grows.

\subsubsection{Complete XOR histories still have a growing number of
terms}\label{complete-xor-histories-still-have-a-growing-number-of-terms}

In the prior symbolic representation, a skipped periodic phase adds a
finite arithmetic segment of actual read positions, and ordinary updates
add singletons. Starting from an explicit m-black input, every generated
term endpoint up to n events is an actual read location covered by (B1);
original singleton terms also lie in that hull. This is true BEFORE
syntactic cancellations, since a term is produced from a genuine finite
path, not from invented archive filling. Each nontrivial segment has
nonzero integer stride, so its length is at most W+10Qn+1 (distance
between its two endpoints is length-1 times a norm \textgreater=1). If
initial absolute coordinate bit length is b, endpoints and lengths thus
have bit length

\begin{verbatim}
O(b+D+log(n+1)),                                        (GEO9)
\end{verbatim}

improving the earlier O(b+n(D+1)) estimate from the exponential
deadline. The NUMBER of terms can still grow as m+n(9Q+1). Thus (GEO9)
is NOT a constant-size memory theorem, not a finite-state quotient, and
not logarithmic-in-n runtime. Temporary inverse-history reconstruction
adds at most D additional local moves; it changes neither the returned
state nor this asymptotic bit bound.

\section{Endpoint tubes and spatially filtered
feedback}\label{endpoint-tubes-and-spatially-filtered-feedback}

Throughout this section \(Q=2^D\), and \(T_D\) is the quadratic budget
above, denoted (REMOTE2). For the square argument one may use the
current bound {[}4{]}
\[E(\ell)=\frac{13\cdot3^{\ell-1}-2\ell^2-4\ell-5}{2}.\] The
accompanying remote-feedback implementation retains the conservative
\(8\ell3^\ell+1\) bound, which suffices for the same termination
argument; it does not evaluate huge powers during event filtering.
Neither choice changes the tube lemma or the qualitative feedback
conclusion.

\subsection{Two-endpoint tube for a finite event macro}\label{remote-2}

Start at X with head p.~Suppose its first S\_D event is at offset tau,
at cell e. The macro includes that read and its actual outgoing move, so
its duration is L=tau+1. Let {[}p,e{]} denote the real line segment
between its endpoints.

\textbf{Theorem 1 (endpoint tube and distance-sensitive time).} Every
head position from time 0 through time tau+1 is in

\begin{verbatim}
[p,e] + [-(3Q+1),3Q+1]^2.                                (REMOTE3)
\end{verbatim}

Every changed cell is in the same tube, and

\begin{verbatim}
L <= Q*||e-p||_infinity + 5*Q^2.                         (REMOTE4)
\end{verbatim}

The tube does not depend on the radius or cardinality of B. Unchanged
black cells outside it remain physically present; (REMOTE3) does NOT
enclose the full input black field. A forever event-free trajectory is
expressly outside the premise.

\subsubsection{Proof}\label{proof}

Until the first event, the actual turns agree with the autonomous suffix
predictor. Its word has a prefix of length j\textless=Q and a cycle u of
length P\textless=Q. If the event occurs in that prefix, its whole path
and actual outgoing move are within Q+1 of p, sufficient for
(REMOTE3)--(REMOTE4).

Otherwise let a be the head after the j-step prefix, and v\_i the
relative pre-update phase positions of u. Then
\textbar\textbar a-p\textbar\textbar\textless=j and
\textbar\textbar v\_i\textbar\textbar\textless=P.

First suppose u restores heading and has nonzero displacement d.~Write
the event as phase i, epoch k, so

\begin{verbatim}
e=a+v_i+k*d.
\end{verbatim}

When k\textgreater=1, any earlier phase position in epoch ell\textless=k
has

\begin{verbatim}
a+v_s+ell*d = (1-lambda)*a+lambda*e+v_s-lambda*v_i,
lambda=ell/k in [0,1].                                  (REMOTE5)
\end{verbatim}

The error has l\_infinity norm at most 2P. Moving a to p costs at most
j; the prefix is within j of p as well. For k=0 all cycle-prefix
positions are within j+P of p directly. Thus all positions through the
event read lie in {[}p,e{]}+{[}-3Q,3Q{]}\^{}2. The TRUE mismatched
outgoing move costs at most one more.

Also, since d is a nonzero integer vector,

\begin{verbatim}
k <= k*||d|| <= ||e-p||+j+P.
\end{verbatim}

Hence

\begin{verbatim}
tau+1 = j+k*P+i+1
       <= Q*||e-p||+2Q^2+2Q
       <= Q*||e-p||+5Q^2.                               (REMOTE6)
\end{verbatim}

If the cycle rotates heading, repeat it twice or four times to restore
heading. The resulting geometric block is closed, since its successively
rotated drift vectors sum to zero. If heading is already restored with
d=0, use one copy. The closed block has length at most 4P; its footprint
is within 2P of a, because a point on a closed unit-step walk is reached
by either side of the loop. Thus (REMOTE3) again holds. Two physically
valid copies of a closed block would repeat the complete state (every
cell is toggled an even number of times), impossible by classical
unboundedness or the strict clock. Consequently
tau+1\textless=j+8P\textless=9Q, which is at most 5Q\^{}2 because
Q\textgreater=2. This proves (REMOTE4) also in the closed cases. Every
changed cell was a read position, proving the final assertion.
\(\square\)

This argument needs only a finite macro to its first event, not a
presumption that any candidate predictor cycle is physically realizable
forever.

\subsection{The event skeleton carries the large-scale
geometry}\label{remote-3}

List the actual S\_D event times t\_1\textless t\_2\textless\ldots{} and
cells e\_i. Put

\begin{verbatim}
H_D=3Q+2,
J_m=||e_1-p_0|| + sum_(i=1 to m-1) ||e_(i+1)-e_i||,
s_m=t_m+1.
\end{verbatim}

\textbf{Corollary 2.} Up to the complete post-mth-event state, the
entire head path is contained in the H\_D-neighbourhood of the polygonal
chain

\begin{verbatim}
p_0 -> e_1 -> ... -> e_m,                                (REMOTE7)
\end{verbatim}

and

\begin{verbatim}
J_m+1 <= s_m <= Q*J_m+6Q^2*m.                           (REMOTE8)
\end{verbatim}

In particular, all changed cells are in that tube; the complete state
still contains every unaltered initial black cell outside it.

Proof: each later macro starts one unit from e\_i. Replacing that start
by e\_i in (REMOTE3) adds at most one to the tube radius. Sum (REMOTE4),
bounding each later source-to-event distance by
\textbar\textbar e\_(i+1)-e\_i\textbar\textbar+1. The lower bound
follows from unit-speed motion between the actual event cells.
\(\square\)

For every real linear functional a, the maximum of a.p\_s over this
prefix lies between max(a.p\_0,a.e\_1,\ldots,a.e\_m) and that value plus
H\_D*\textbar\textbar a\textbar\textbar\_1. Thus, on an infinite event
chain, any direction in which the head is unbounded above is also a
direction in which these event locations are unbounded above. This is a
statement about directional ranges, not limiting speeds or angular
convergence.

This is stronger than using the convex hull of the WHOLE black field:
far, untouched black debris does not enlarge the event-to-event tube. It
is not an assertion that the event skeleton itself is bounded or
eventually straight.

\subsection{A finite-region burst bound, independent of the outside
field}\label{remote-4}

Let K be a nonempty FIXED finite set of lattice cells, w its l\_infinity
diameter, and choose an axis-aligned square enclosing
K+{[}-H\_D,H\_D{]}\^{}2. A sufficient side is

\begin{verbatim}
ell(K,D)=w+2H_D+1,
b(K,D)=E(ell(K,D)).                                     (REMOTE9)
\end{verbatim}

\textbf{Theorem 3 (bounded internal bursts).} A consecutive run in the
EVENT LIST whose event cells all belong to K has length at most b(K,D).
The bound is independent of the rest of the complete black field and of
the starting time.

Proof: start immediately before the first event of that run. Corollary 2
keeps the whole actual path, through every completed internal event in
the run, inside the square in (REMOTE9). Its first exit is no later than
E(ell). Thus the elapsed time through any such consecutive completed run
is strictly less than E(ell), and the number of distinct event reads is
at most that elapsed time. The slightly weaker integer bound b is
sufficient. Exterior colours can be arbitrary because they stay
unchanged before first exit. \(\square\)

The word `consecutive' refers to events, not ordinary updates. The ant
may execute many non-event updates between them. Neither infinite local
oscillation nor arbitrarily much exterior storage invalidates this
uniform bound.

\textbf{Corollary 4 (joint, not merely separate, escape).} For each
fixed D, an orbit has infinitely many S\_D events if and only if their
positions form an unbounded set. If the events are infinite, infinitely
many lie outside EVERY fixed finite K.

An infinite tail confined to K would contradict Theorem 3 after its last
external event. A finite event list has a finite position set, giving
the reverse direction. This is not a claim that e\_i tends to infinity:
returns to K can occur infinitely often, interleaved with external
events.

\subsection{A genuinely total spatially filtered event
algorithm}\label{remote-5}

\textbf{Theorem 5.} Uniformly in a complete finite X, integer
D\textgreater=1 and explicitly supplied finite K, the following
predicate is decidable:

\begin{verbatim}
exists t>=0: S_D(F^t X) and pos(F^t X) not in K.          (REMOTE10)
\end{verbatim}

The algorithm returns the FIRST such event, when one exists. A negative
answer also certifies eventual nonzero translating periodicity, but need
not certify standard P104.

Algorithm: call the already-total next-event procedure. If it certifies
no future S\_D, return NO\_EXTERNAL\_EVENT and its periodic certificate.
If its event cell is outside K, return that event and accumulated time.
Otherwise execute the finite prefix through that event with the complete
field retained and repeat.

Every individual query and finite replay terminates. Were the outer loop
infinite, there would be infinitely many S\_D events all in K,
contradicting Corollary 4. This supplies the previously missing
loop-termination proof; it is not a chosen resource cap. More
quantitatively, use K union \{p\_0\} in (REMOTE9): every completed
inside-only prefix has its whole path inside that square, so fewer than
its E(ell) literal updates, hence at most E(ell) internal events, can
precede the final query. The final external event itself may be
arbitrarily distant in time. For K empty, the original next-event
procedure suffices directly.

The implementation leaves E(ell) symbolic, instead of attempting to
construct an integer such as 3\^{}(6*2\^{}128). It uses literal replay
of inside-event intervals; no efficient full symbolic continuation is
claimed for huge inside intervals. Optional resource limits return
INCONCLUSIVE, NEVER a false negative answer.

\subsubsection{An explicit first-external-event
deadline}\label{an-explicit-first-external-event-deadline}

Let R\_0=max\_\{q in B\_0\}\textbar\textbar q-p\_0\textbar\textbar{}
(zero for empty B), and use ell\_0=ell(K union \{p\_0\},D). If an
external event exists, its FIRST time is strictly less than

\begin{verbatim}
(Q+1)*E(ell_0)+Q*(R_0+2Q+10).                           (REMOTE10a)
\end{verbatim}

Indeed, the head first exits the guard square at some
tau\textless=E(ell\_0). Either an external event has already occurred,
or all preceding event cells are in K. In the latter case the NEXT S\_D
after tau, if present, cannot be in K: otherwise (REMOTE7) would enclose
the whole prefix through it inside that square, contradicting the exit
at tau. Apply the existing first-event waiting bound at X\_tau, using
R(X\_tau)\textless=R\_0+tau. If there is no next event, there is no
external event at all. This is also a direct two-stage decision proof,
independent of the loop argument.

For fixed D and fixed K in the normalized p\_0=0 frame, the filtered
predicate is polynomial-time in the sparse binary-coordinate input
encoding, using the existing fixed-D polynomial-time next-event
procedure. There are only constantly many internal events, and the TOTAL
literal inside-prefix replay is bounded by E(ell\_0), a constant in this
fixed-parameter assertion. These constants can be enormous; no practical
efficiency or uniform polynomial bound in D,K is claimed.

Why this is more than the old first-event test: the first many S\_D
events can occur inside K and must be ignored. The earlier fixed-n event
theorem alone does not say when that filtering loop stops. The endpoint
tube plus finite-domain escape now proves that it always does.

\subsection{Quantitative exterior feedback on every infinite event
chain}\label{remote-6}

Let N\_D(t) count all S\_D reads at offsets 0\textless=s\textless t, and
M\_(D,K)(t) count those outside fixed K. Internal events occur in at
most M+1 runs. Theorem 3 gives

\begin{verbatim}
N_D(t) <= b+(b+1)*M_(D,K)(t),
M_(D,K)(t) >= floor(N_D(t)/(b+1)).                       (REMOTE11)
\end{verbatim}

For an infinite S\_D chain, define the computable integer

\begin{verbatim}
n_D(t,W)=max{n>=0:T_D(n,W)<=t},                          (REMOTE12)
\end{verbatim}

with the retained deadline (REMOTE2). It follows that

\begin{verbatim}
M_(D,K)(t) >= floor(n_D(t,W)/(b+1)).                     (REMOTE13)
\end{verbatim}

For fixed X,D,K, this is an Omega(sqrt(t)) lower bound as t tends to
infinity, with a very large fixed denominator b+1. It is not an asserted
optimal density. No independent-bit count or computational power
conclusion follows from it. For empty K, use M=N and b=0. No finite
observation can establish the premise that the entire chain is infinite.

\subsubsection{A stronger exterior-only quadratic
deadline}\label{a-stronger-exterior-only-quadratic-deadline}

The factor b+1 in (REMOTE13) can be avoided in the LEADING quadratic
coefficient. Augment the state hull by the observation region:

\begin{verbatim}
C_K(X)=conv(B union {p} union K),
W_K=diam_infinity(C_K(X_0)).
\end{verbatim}

A finite macro ending just after the FIRST EXTERNAL S\_D event satisfies

\begin{verbatim}
C_K(X_new) subset C_K(X)+[-9Q,9Q]^2,                    (REMOTE13a)
duration <= 2Q*diam_infinity(C_K(X))+20Q^2+b.            (REMOTE13b)
\end{verbatim}

To prove (REMOTE13a), if there are internal events, their entire prefix
is in conv(\{p\} union K)+{[}-H\_D,H\_D{]}\^{}2 by (REMOTE7). The full
field at the last internal post-event state is therefore in
C\_K(X)+{[}-H\_D,H\_D{]}\^{}2, WITHOUT dropping the initial field. Apply
the retained 5Q next-event convex-halo theorem to the final ordinary
event macro. Since H\_D+5Q=8Q+2\textless=9Q, (REMOTE13a) follows. With
no internal event, the original 5Q bound is already sufficient.

For (REMOTE13b), (REMOTE4) bounds the first internal event duration by
\[Q\operatorname{diam}(C_K(X))+5Q^2.\]
From its pre-read state through the last internal post-event state there are
fewer than \(b\) further updates, by the burst proof. At that boundary the
complete head-relative radius is at most \(W+2H_D=W+6Q+4\).
The first-event estimate makes the last macro at most \(Q(W+8Q+14)\)
updates. Adding these conservative bounds gives
\[
2QW+13Q^2+14Q+b\le2QW+20Q^2+b,
\]
since \(Q\ge2\). With no internal event, the original
\(Q(W+2Q+10)\) estimate is smaller. Overcounting the first internal read
only weakens the bound. For empty \(K\), use \(b=0\).

After n EXTERNAL events, (REMOTE13a) gives augmented width at most
W\_K+18Qn. Consequently the post-nth-external-event time, IF PRESENT,
satisfies

\begin{verbatim}
U_(D,K)(n,W_K)
  = n*(2QW_K+20Q^2+b)+18Q^2*n*(n-1).                  (REMOTE13c)
\end{verbatim}

On an infinite chain,

\begin{verbatim}
M_(D,K)(t) >= max{n>=0: U_(D,K)(n,W_K)<=t}.             (REMOTE13d)
\end{verbatim}

For every fixed K this lower bound has leading asymptotic coefficient
\(\sqrt{t}/(\sqrt{18}Q)\), INDEPENDENT of K. The linear coefficient
and the onset of that asymptotic regime can grow enormously with K
through b. There is no assertion of an estimate uniform in regions K
that grow with time. The new spatial expansion is in EXTERNAL event
count; the weaker bound obtained by multiplying the old all-event
deadline by the internal burst count is not used.

\subsection{Simultaneously remote, late-born, arbitrarily long black
lifetimes}\label{remote-7}

An orbit that is NOT eventually a nonzero translating periodic trace has
infinitely many S\_D for EVERY D, by the existing stale-memory theorem.

\textbf{Theorem 6 (remote long feedback necessity).} On every such
orbit, for every D\textgreater=1, finite K, and time T, there are
infinitely many cells/lifetimes described by times b,e with

\begin{verbatim}
T < b < e,       e-b>D,       x not in K,
update b reads x white and makes it black,
update e is its NEXT read, black.                       (REMOTE14)
\end{verbatim}

These lifetimes can be chosen at infinitely many DISTINCT, unbounded
cells. This does not assert that the whole event sequence eventually
avoids each cell.

Proof: restart at the complete state at time T+1. Corollary 4 supplies
infinitely many later S\_D events outside K. At most
\textbar B\_(T+1)\textbar{} can consume black lifetimes already present
at the restart. Every other such read consumes a lifetime born at a real
forward white update b\textgreater=T+1, at the same exterior cell. The
intrinsic S\_D condition then forces e-b\textgreater D. There was no
intermediate read because black lifetimes end at their next read.
Removing the finitely many initial-lifetime events from an unbounded
event-position set leaves an unbounded set, so the surviving lifetimes
can be chosen at infinitely many distinct cells. Equations (REMOTE13)
and (REMOTE13d) also give count bounds after subtracting the finite
stock. \(\square\)

This is a genuine quantifier strengthening. Separately knowing `some
blockers are arbitrarily distant' and `some lifetimes are arbitrarily
long' does NOT imply (REMOTE14); those could have been different
families. The endpoint-tube argument is what forces long-lived feedback
to recur outside every finite region.

It concerns literal S\_D consumptions. It must not be relabelled as a
theorem that the same long-lived cells are PG primary/secondary
blockers: some S\_D events can occur inside one PG macro, and no
transfer theorem is proved here.

\subsection{Precise consequence for the attempted global
bound}\label{circuit-5}

Let N\_D(b,e) count S\_D reads strictly between a black lifetime's birth
and its consumption. On all complete finite-support classical inputs

\begin{verbatim}

\end{verbatim}

for every post-input-created consumed black lifetime. In this family the
three arguments are fixed at (128,31,20), while e-b=624n-1576 is
unbounded. The same examples refute a bound in terms of an upper budget
m=31 and M=20. Their excursion radius is unbounded as well.

By contrast, the zero-intervening-event estimate remains true. At a
white birth b there is no S\_D event. If e-b\textgreater D and there is
none in (b,e), the death is the FIRST S\_D from X\_b and its
source/event positions are equal. The endpoint-tube time estimate gives
e-b+1\textless=5*4\^{}D. If e-b\textless=D the weaker bound
e-b\textless=5*4\^{}D is immediate. Thus

\begin{verbatim}
N_D(b,e)=0 => e-b<=5*4^D.                                (CIRCUIT9)
\end{verbatim}

Equation (CIRCUIT9) is a direct corollary of the retained theorem, not a
separate rediscovery of its predictor proof. The false step was
extending it across an arbitrary finite number of intervening events
without carrying spatial scale.

No bound depending on the complete input, its coordinate bit length or

diam(B\_0)=Theta(n). The retained quadratic event deadline explicitly
includes input diameter and is fully consistent with these linear-in-n
delays. Nor does this show that one fixed seed has unbounded lifetimes,
