# Newly generated remote feedback: exact detection and growing-scale necessity

This is research on the non-eventually-periodic branch of finite-support HC.
It does not solve that branch. [PROOF.md](PROOF.md) separates inherited qualitative
remote feedback from the new first-witness operator and growing-scale bounds.

- `python reproduce.py` runs every dedicated check in a temporary directory.
- `python reproduce.py --output /tmp/birth-feedback` also keeps rebuilt full reports.
- Only Python 3.10+ standard library is needed. Do not use `python -O`.

`code/renewal.py` returns the FIRST remote old black lifetime born AFTER the source
checkpoint, including its exact birth, death, and complete XOR-segment post-state.
Initial coordinates can qualify after being erased and rewritten. The negative
answer `NO_FRESH_EXTERNAL` certifies eventual nonzero translating periodicity,
not that the seed fails HC or that its translator is necessarily standard.
Optional resource caps return `INCONCLUSIVE`.

Example:

```python
import sys
sys.path.insert(0, 'code')
from renewal import State, fresh_feedback, summary
print(summary(fresh_feedback(State.explicit([]), 128, set())))
# Birth 21, death 197, age 176; the complete post-state is in the returned object.
```

Every black cell, including untouched off-path debris, remains represented.
Huge deadlines are represented by `deadline_parts()` rather than expanded.
`growing_scale_floor()` evaluates a necessary bound UNDER A NON-ETC PREMISE;
it does not decide whether that premise is true.

The committed concise certificate file `evidence/checked_summary.json` pins the
sources and full deterministic reports. All reports are regenerated by `check.py`.
The distributed conversation archive additionally includes the expanded reports.
Hashes identify data; the actual arithmetic, literal replays and proof establish
what is checked. No optimizer, simulator change, external publication or other
repository test suite is part of this update.
