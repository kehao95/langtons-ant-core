# Prefix-hit one-black cases

The arbitrary-offset reduction has a finite exceptional domain: the squares
read before blank P104 entry. `blank_entry_prefix_schedule()` derives its 1,376
points in first-read order, retaining both the point and the update at which it
is first encountered.

This ordered schedule is the only acceptable index for a future finite
certificate. A case closure must either attach one terminating trace to every
schedule entry or prove a partition whose coverage is checked against this
derived schedule. Omitting a point, silently changing an orientation, or using
a global simulation limit is not a closure.
