# 下一轮问题地图：从机制解释到可验证的新数学

**Research agenda / 可证伪计划** · 2026-10-30

本文不是 HC 的新证明、也不是已经申请发表的理论；它记录可重启的研究入口、应拒绝的错误推理、和明确的成功条件。请先读 [机制论证](SELF_WRITING_MEDIA.md)，再返回每个子模块的 `PROOF.md` 与证书。

## 第一优先级：完整残余的持久响应等价

**核心问题。** 存不存在一个非平凡的、可有效描述的“散射后完整状态类型”，能在**重复真实碰撞且不重置历史**时闭合？如果不存在，能否构造一族不断增加的区分上下文，证明给定接口的响应类型复杂度下界？

**精确研究对象。** 固定入射/出射的朝向、相位、物理坐标变换及一个明确允许的后续请求类 `I`。所有微观状态仍包含完整有限黑场。两状态只在各个允许的真实请求序列都产生相同回复与同类型残余时才可合并。不能把任意外部“重新放置头部”的请求冒充一个自主单蚂蚁轨迹。

**最小实验与升级路径：**
1. 从 [four_row_escape](../four_row_escape/) 的**同侧持久接口**复核“保持残余、组合封闭”的真正逻辑，不移植269这个数字到全平面。
2. 从 [four_cell_port](../four_cell_port/) 的受保护单次散射、[one_black](../one_black/) 的完整高速历史，选择固定的两个真实连续碰撞，**逐格**核验全部残余。
3. 对相同一期的候选宏状态做第二次碰撞；若未来响应不同，保存最短的“区分后缀”，修订状态信息或给出有限型假说的反例。
4. 仅在提出有限目录或参数化目录并证明覆盖、可实现性、残余闭包、守卫与归纳后，称其为宏观转移定理。

**成功标准：** 对无界的**明确输入族**给出全参数闭包证明，或证明其上下文区分数无界（范围写清楚）。**失败模式：** 单次散射可恢复P104，却留下可被下一次碰撞读取的未纳入残余。

## 第二优先级：因果记忆的可计算有限时域与不可压缩性

**核心问题。** 同样大的已写历史，为什么有些差异仍会控制未来，而有些差异已经不再影响指定观察？

对于一份完整状态 `X` 和**有限**观察时域 `T`，定义扰动响应：先翻转候选格子 `q`，比较原轨迹与扰动轨迹的前 `T` 步转向/位置序列。被读取且改变结果的格子构成一个可有限枚举的影响集（只需考察未扰动轨迹在时域内读到的格子；否则首次差异不可能发生）。这不是“对无限未来永远无影响”的判定算法。

**最小实验：** 对 [defect_synthesis](../defect_synthesis/) 的六格折返、[memory_feedback](../memory_feedback/) 的久远寿命、[four_cell_port](../four_cell_port/) 的已保护尾迹，比较扰动的响应时滞、坐标距离、读回时间与完整场的剩余差分。记录扰动可能被再激活的最小上下文，不只记录黑格总数。

**成功标准：** 证明一条对无界参数成立的“守卫足以确保有限/永久不影响”定理，或为某个预测接口证明不可消除的历史区分下界。**失败模式：** 用未来不可读集合当成当前可计算的商；把一次轨迹中未读当作所有后续交互都未读。

## 第三优先级：增长—违例的可实现区域，而非热力学口号

设一条完整轨迹的两个极限**存在**：
```text
rho = lim_T (|B_T|-|B_0|)/T,
j   = lim_T N10(0,T)/T .
```
[factor_language](../factor_language/) 的普适不等式立即给出 `26rho+351j>=3`。这只是已有结论的推论，**不是新定理**。P104 对应 `(rho,j)=(3/26,0)`；`j=0` 不等价于只有有限个违例。

**下一问：** 哪些极限对、或哪些 `liminf/limsup` 行为，真的可由**同一个有限初态的完整无限运行**实现？能否证明一个“稀疏但无限缺陷”类不可能，或精确构造一个真实自主更新的实例？

**成功标准：** 非仅由代数不等式推断的全参数/无限未来分类；对应完整物理构造与归纳/守卫。**失败模式：** 用六格族 `k\to\infty` 的不同时间零初态，代替单个初态沿时间的无限极限。

## 第四优先级：用真正的自主续接接口重新触碰 HC

如果走正向路线，需构造一个作用在**所有所声称输入**上的良基终止机制：允许静默段制造后续可读黑格；秩不得只依赖原始黑格数或固定的标量圈秩。若走负向路线，需要明确一个固定有限 `X_0`，完整状态 `X_k` 与严格正整数 `l_k` 满足
```text
F^(l_k)(X_k) = X_(k+1)
```
并通过所有未来阶段的防干扰守卫证明无限多真实非标准事件，不能借助不断换种子、预装越来越远的标记或外部重置。

**与 HC 的关系：** 条件式响应代数的成功不等于 HC；若要改变全局前沿，必须再证明其接口覆盖每个所涉及的反例分支（或建立直接的精确双向归约）。周期尾迹的有限分类也不等于所有轨迹最终周期化。

## 在开展新研究时必须执行的检查

| 试图声称 | 最少需要的证据 |
|---|---|
| 一个有限/半线性宏观状态模型 | 完整定义、所有真实输入与边的覆盖、残余回复闭包、可实现性、独立有限核 |
| 某个散射类全参数收敛 | 真实完整颜色场递推、有限与半无限守卫、全部异常相位、准确首次入口与完整未来 |
| 某类无限行为不可能 | 全称条件下的良基秩、覆盖或矛盾；超时/有限样本不能充当证明 |
| 经典蚂蚁的非标准无限反例 | **一个固定有限初态**，无穷多个真实事件和自主物理归纳 |
| “计数器”“热力学”“相变”“可积系统” | 各自额外的编码—转移律、统计结构、序参量或多散射闭包，不接受单凭名称 |

**下次从何处重新开始？** 先尝试第一优先级里**两次连续真实碰撞后的同一类残余响应**。如果失败，保存最小反例和哪项历史信息导致区别；如果成功，再把两次扩充到任意有限次。该实验有明确的正负输出，而且比再次优化一个有限 J10 上界更贴近“简单规则为何涌现新的高层动力学”这一原始问题。
