# Reproduction and certificate scope

The attraction proof uses an all-parameter physical fold exclusion.
Its finite word graph, event macros, mass potentials, supply and archive
constructions have separate exact checkers in `../verification/`.
The mass inequality uses finite-word coverage independently of infinite-future
attraction. The default entrypoint checks all modules; scoped options are listed
in the project README. Python and C++ implement separate finite controls.

```sh
python3 factor_language/reproduce.py
```
